# Week 1 - Day 1 Notes

## What I Learned

- HTML gives structure and meaning to webpages.
- Semantic HTML helps describe what content represents.
- The browser interprets HTML and renders the page.

## Important Tags

### Structure

- `<html>` - The root element
- `<head>` - Information about the page
- `<body>` - Visible content

### Semantic Elements

- `<header>` - Introductory content
- `<nav>` - Navigation links
- `<main>` - Primary page content
- `<section>` - Related content grouping
- `<article>` - Standalone content
- `<footer>` - Closing information
